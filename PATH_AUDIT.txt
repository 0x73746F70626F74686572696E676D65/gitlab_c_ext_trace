TOP SOURCE-PROVEN ERROR CAUSES
- Argument-insensitive composition: fixed Hash reaches String-only JSONSchemer branch; fixed :rails mode reaches Oj strict-mode branch; one-argument/no-block constructors reach zero-argument/block-only primitives.
- Ruby ancestor union ignores overriding definitions: HTML5 Document.parse incorrectly selected inherited HTML4.parse despite an own implementation.
- Missing guard/activation semantics: absent :x5c or nil options reach guarded JWT/JSON internals; a deferred lambda body is traversed without showing invocation.
- Unresolved evidence includes optional JSON backend activation and unproven internal C state/macro contracts.

GLOBAL PATH RECALL: UNKNOWN
An exhaustive true path denominator is unavailable. Loops, dynamic dispatch, callbacks, generated/native build variants, source blockers, conditional loading and solver bounds prevent a defensible single total coverage percentage. Enumeration keeps one shortest Ruby witness per entrypoint/registration and representative C tails; new Ruby traversal depth8/256methods, reused suffixes may be longer, repeated methods collapse. These are explicit coverage limits.

TRUST RECOMMENDATION
Use this corpus to find and inspect candidate code, with audit verdicts and explicit gaps. Do not use the raw end-to-end totals as established user reachability or a security impact count. Fix method precedence, argument-sensitive branches, callback/super handling and backend activation in a new separately identified revision, then repeat the same audit plus a fresh holdout sample.
