Separate coverage additions, not integrated complete paths
profiles/{ce,ee}/tables/route_scope_* follow literal draw/draw_all in caller namespaces. Direct route tuple bindings rise CE 785→1,092 and EE 1,095→1,451, not counts of newly proven paths. Resource inflection, dynamic DSL and edition activation remain qualified.
controller_callback_* preserves scoped callbacks, literal action filters, candidate targets, skips and order/halting holes. Every callback demand is partial; action execution is not implied.

request_arg_candidates is a ranked automatic review queue (five profile-specific records, three distinct source sites), separate from reviewed memory-flow contracts. source_supported only describes local value-transfer holes; binding conditions and auth remain unresolved.

Data and joins
Stable baseline path_id joins overlay path decisions; profile disambiguates CE/EE. Ruby and native IDs refer to preserved source analysis catalogs. Tables contain source file/line and evidence references. scope_occurrence_id joins route/callback candidates, callback_id joins declarations/skips, and method IDs join the original profile Ruby method inventory. This compact companion intentionally omits bulk sources, full ASTs and full call tables, so some joins require the prior artifacts or saved workspace. Source paths resolve relative to /workspace/gitlab_c_ext_trace. Supporting excerpts in review dossiers are evidence, not full retained trees.

Package integrity and reproduction
The authoritative included-file catalog is table_catalog.json (bytes, SHA256, JSONL row counts). SHA256SUMS covers staged content except itself. package_validation.json records manifest checks; the external publication/archive_validation.json verifies archive membership and content bytes. Do not confuse archive hashes with table hashes or source provenance.

Run from the saved /workspace/gitlab_c_ext_v3 environment:
  python scripts/package_v3_publication.py
The deterministic archive normalizes paths, timestamps, ownership and gzip metadata. Final packing requires iteration2/native freeze files and no pending EE states in the flow validation report. --provisional produces explicitly nonfinal staging. Analysis scripts require the retained sources, previous input tables and pinned parser tooling under /workspace/gitlab_c_ext_trace; the compact archive alone is not a standalone replacement for those inputs.

No changes to frozen sources, prior overlays or baseline history are authorized by extraction or packing. Detailed scope limits and per-rule tests are retained in reports/, scripts/, tests/ and fixtures/.
